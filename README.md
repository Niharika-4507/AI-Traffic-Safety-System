# AI-Powered Intelligent Traffic Safety & Incident Response System

An AI-based system designed to detect road accidents using traffic camera footage and support faster incident response.

## Features

- Accident detection using YOLOv8.
- Temporal validation of accident detections.
- Camera and incident management.
- Incident evidence storage.
- Emergency dispatch logging.
- Web dashboard for monitoring incidents.

## Technologies Used

- **AI/ML:** Python, YOLOv8
- **Backend:** FastAPI
- **Frontend:** React, Vite, Tailwind CSS
- **Database:** SQLite, SQLAlchemy

## Project Structure

- `ai_engine/` – Accident detection and temporal validation.
- `backend/` – FastAPI backend and API routes.
- `frontend/` – React dashboard.
- `data/` – Dataset manifests and evaluation results.
- `docs/` – Project documentation.
- `scripts/` – Testing and verification scripts.

## Current Status

**In Progress** – Core accident detection, backend APIs, database integration and dashboard development are underway.
